# Theorem 19 — Semantic anchors are necessary beyond marginal alignment

## Status

**Counterexample plus a sufficient-statistic preservation theorem.**

## Purpose

A transport can perfectly match representation marginals while reversing fault
semantics. A canonicalizer therefore needs paired physical anchors or a
preserved task-sufficient statistic.

## 1. Proposition 19.1 — marginal equality permits semantic reversal

Let \(Y\sim\mathrm{Bernoulli}(1/2)\). Define

\[
C_1=Y,
\qquad
C_2=1-Y.
\]

Then

\[
\operatorname{Law}(C_1)
=
\operatorname{Law}(C_2)
=
\mathrm{Bernoulli}(1/2),
\]

but a classifier \(h(c)=c\) has zero error in domain 1 and unit error in domain
2.

### Proof

The marginal statement follows from balance. The label relation is identity in
domain 1 and reversal in domain 2. ∎

This counterexample applies to MMD, adversarial confusion and Wasserstein
marginal matching when no semantic correspondence is imposed.

## 2. Definition — task-sufficient semantic statistic

A statistic \(\psi(C)\) is task sufficient when

\[
Y\perp\!\!\!\perp C\mid\psi(C).
\]

A canonicalizer preserves the statistic when there exists a measurable decoder
\(r\) such that

\[
r(T_d(C))=\psi(C)
\quad\text{almost surely}.
\]

## 3. Theorem 19 — preservation of a sufficient semantic statistic preserves Bayes information

Under the two preceding conditions,

\[
Y\perp\!\!\!\perp C\mid T_d(C).
\]

Consequently every Bayes decision based on \(C\) has an equivalent decision
based on \(T_d(C)\).

### Detailed proof

Because \(r(T_d(C))=\psi(C)\), the sigma-algebra generated by \(\psi(C)\) is
contained in that generated by \(T_d(C)\). Task sufficiency gives

\[
p(y\mid C)=p(y\mid\psi(C)).
\]

Since \(\psi(C)\) is a measurable function of \(T_d(C)\),

\[
p(y\mid C,T_d(C))
=
p(y\mid\psi(C))
=
p(y\mid T_d(C)),
\]

where the last equality follows by conditioning on the richer variable
\(T_d(C)\) that contains \(\psi(C)\). This is the definition of the stated
conditional independence. Bayes actions depend only on the conditional law of
\(Y\), so they can be written as functions of \(T_d(C)\). ∎

## 4. Practical anchors

A credible anchor may be:

- the same `latent_event_id` observed by two acquisitions;
- a known modal state from a simulator;
- fixed frequency/damping slot identity;
- a source-only fault concept known to be task sufficient;
- a paired high-fidelity reference view.

Dataset identity is not a semantic anchor.

## 5. Failure boundaries

1. The chosen statistic may not be task sufficient.
2. A source-sufficient statistic may shift in the target domain.
3. Pairing by class rather than event does not preserve event semantics.
4. A class label can be too coarse to anchor modal phase or severity.
5. A learned decoder \(r\) can fail even if an ideal one exists.

## 6. Experimental implication

Include a class-permutation negative control with identical marginals. Report
paired or class-conditional retrieval in addition to marginal discrepancy.
Flow is promoted only when it reduces acquisition variation while preserving
the declared semantic statistic.
